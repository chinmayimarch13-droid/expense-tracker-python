# Expense Tracker using Python

A simple console-based Expense Tracker built using Python.
It helps users record daily expenses and calculate total spending.

## Features
- Add daily expenses
- View all expenses
- Calculate total amount spent
- Store data using file handling

## Technologies Used
- Python
- File Handling
- Git & GitHub

## How to Run
1. Clone the repository
2. Open terminal in project folder
3. Run:
   python expense_tracker.py

## Sample Output
1. Add Expense
2. View Expenses
3. Exit
